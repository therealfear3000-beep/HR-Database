# HR Database — Accuracy-First Quiz Toolkit

An extensible, source-traceable HR knowledge base and two operational skills:
- [Universal Quiz Solver](skills/universal-quiz-solver/SKILL.md): image-based MCQs across HR, OB, aptitude, analytics, finance, MBA subjects, and general awareness.
- [HR Knowledge Updater](skills/hr-knowledge-updater/SKILL.md): maintain source-grounded notes from new documents without fabricating evidence.

## Usage
**Preparation:** Ask: "Prepare for a quiz using therealfear3000-beep/HR-Database." Retrieve the relevant trusted reference cards, prioritize topic coverage, and keep source locations available. Preloading is not permanent memory.

**Live quiz:** Ask: "Follow skills/universal-quiz-solver/SKILL.md. Return the answer only." Provide question images one at a time. A short final answer does **not** mean skipping checks. Verify risky questions selectively.

**Maintenance:** Ask: "Follow skills/hr-knowledge-updater/SKILL.md and update this repository using my new uploads." Changes should be source checked and reviewed before trusting them.

## Knowledge policy
- `knowledge/verified/`: only traceable claims with exact document location and checked evidence; do not add unverified claims.
- `knowledge/review/`: candidate notes, ambiguities, and claims awaiting citation or legal/current verification.
- `sources/manifest.md`: inventory of provided reference material; listing a source does NOT mean its content is stored in GitHub or fully verified.
- `skills/`: executable instructions (not a guarantee of model/tool behavior).
- `tests/`: regression questions and their reference answers.

**Copyright and privacy:** This repository was public when initialized. No uploaded PDFs, textbook scans, or proprietary materials are included. Do not push such files without rights and an explicit review. Make the repo private in GitHub settings if you intend to store sensitive or licensed files.

**Accuracy disclaimer:** No workflow guarantees 100% accuracy. The solver must express uncertainty rather than invent an answer or citation. `knowledge/verified/` is not a substitute for checking current legislation or news.
